Linux · Hors ligne

localStorage · sans serveur · .desktop auto-installant

📦 Étape 1 : Récupérer les fichiers

  • 1 Télécharge l'archive BisoOffice et extrais-la dans un dossier, ex : ~/BisoOffice/
  • 2 Vérifie la présence de : index.html, parametres.html, screen_client.html, bisooffice.desktop
  • 3 Tous les fichiers doivent rester dans le même dossier — les liens sont relatifs
💡 Recommandé : place le dossier dans ~/Bureau/BisoOffice/ pour le retrouver facilement

🚀 Étape 2 : Lancer le .desktop

  • 1 Double-clique sur bisooffice.desktop — ou clic droit → Lancer
  • 2 Au premier lancement, le script installe automatiquement Node.js et npm si absents
  • 3 Un terminal s'ouvre brièvement pour l'installation, puis BisoOffice s'ouvre dans le navigateur
  • 4 Si le navigateur ne s'ouvre pas : ouvre Chrome/Firefox et accède à file:///~/BisoOffice/index.html
🔑 Si une demande de mot de passe apparaît (sudo), c'est normal — c'est pour installer Node.js au niveau système

⚙️ Étape 3 : Configurer l'entreprise

  • 1 Va dans Administration → Paramètres (parametres.html)
  • 2 Remplis : nom, numéro d'entreprise, adresse, téléphone, logo
  • 3 Configure la banque : nom, IBAN, BIC, communication structurée
  • 4 Active/désactive la TVA et règle les taux selon ton activité
💡 Sur tablette, active le Clavier virtuel ⌨️ en bas de la page Paramètres pour saisir confortablement

💾 Étape 4 : Données & Sauvegardes

  • 1 Toutes les données sont dans le localStorage du navigateur (automatique)
  • 2 Exporte régulièrement : Outils → Plus d'actions → Exporter → fichier JSON
  • 3 Pour restaurer : Outils → Importer et sélectionne ton fichier JSON
  • 4 Ne jamais vider le localStorage du navigateur sans avoir exporté au préalable
⚠️ Changer de navigateur ou de profil = données vides. Reste toujours sur le même navigateur

Linux · En ligne

serveur local · commande gsm · tablette · écran client

🚀 Étape 1 : Lancement automatique

  • 1 Double-clique sur bisooffice.desktop — Node.js et npm s'installent automatiquement si absents
  • 2 Le script démarre un serveur HTTP local (port 8000) et ouvre BisoOffice dans le navigateur
  • 3 Une LED 🟢 apparaît dans l'interface si le serveur est bien actif
  • 4 Ne ferme pas le terminal ouvert par le .desktop — c'est le serveur en cours d'exécution
💡 Commande manuelle : dans le dossier BisoOffice → python3 -m http.server 8000

📡 Étape 2 : Trouver l'adresse IP

  • 1 Ouvre un terminal et tape : ip a ou hostname -I
  • 2 Repère l'adresse IPv4 locale, ex : 192.168.1.42
  • 3 Assure-toi que le PC serveur et les appareils mobiles sont sur le même réseau Wi-Fi
  • 4 Pour une IP fixe : Paramètres réseau → IPv4 → Manuel → assigne une IP statique
📌 Note l'IP, tous les appareils utiliseront : http://192.168.1.42:8000/

📲 Étape 3 : Accès GSM & Tablette

  • 1 Connecte le GSM / la tablette au même réseau Wi-Fi que le serveur Linux
  • 2 Ouvre Chrome (Android) ou Safari (iPhone/iPad)
  • 3 Tape l'adresse : http://192.168.1.42:8000/ (adapte l'IP)
  • 4 Crée un raccourci : menu navigateur → "Ajouter à l'écran d'accueil"
  • 5 Les nouvelles commandes GSM apparaissent avec la cloche 🔔 dans Gestion
🔄 Les données se synchronisent en temps réel entre tous les postes connectés via http://

🖥️ Étape 4 : Écran client

  • 1 Branche un second écran ou utilise une tablette dédiée
  • 2 Ouvre http://192.168.1.42:8000/screen_client.html
  • 3 Clique ⛶ Plein écran pour occuper tout l'affichage
  • 4 L'écran affiche le ticket en cours, le QR de paiement et l'animation de succès en temps réel
  • 5 Personnalise fond et couleurs via le bouton 🎨 Personnaliser
📺 Mise à jour automatique toutes les 100ms — aucune manipulation nécessaire

🔧 Étape 5 : Config finale

  • 1 Configure l'entreprise : Administration → Paramètres (logo, IBAN, TVA…)
  • 2 Crée les utilisateurs avec leur PIN : Administration → Membres
  • 3 Consulte le guide complet : Fonctions.html (6 modules, 36 astuces)
  • 4 Exporte tes données régulièrement : Outils → Plus d'actions → Exporter
✅ Raccourcis : Entrée = valider · Échap = fermer · Ctrl+S = sauvegarde rapide
